# Школа Астеропи — квест по греческому (A2)

Интерактивный квест для учеников, изучающих греческий язык на уровне A2. Пять башен волшебной школы, задания, сундуки с подарками и диплом в конце.

## Что внутри

| Башня | Тема |
|-------|------|
| Η Πύλη (Ворота) | Знакомство и приветствия |
| Η Βιβλιοθήκη (Библиотека) | Артикли, род, глаголы в настоящем |
| Τα Φίλτρα (Зельеварня) | Еда, покупки, заказ |
| Ο Πύργος του Χρόνου (Башня Времени) | Прошедшее время (аорист) |
| Το Μεγάλο Δωμάτιο (Большой зал) | Финальное испытание |

В каждой башне 4 задания: выбор ответа, вставка слова, сборка предложения, поиск пар. После башни открывается сундук с подарком и новым греческим словом.

## Как запустить

Откройте `index.html` в браузере или перейдите по ссылке GitHub Pages.

Прогресс сохраняется в браузере ученика (localStorage). Для шрифтов нужен интернет, без него игра работает со стандартным шрифтом.

## Как изменить задания

Все задания лежат в массиве `LEVELS` в `index.html`. Типы заданий:

- `quiz` — выбор ответа (первый вариант в `opts` считается верным, порядок перемешивается автоматически);
- `order` — сборка предложения (слова перечислены в правильном порядке);
- `match` — пары «греческое слово — перевод».
